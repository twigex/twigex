# Security Policy

Security and data protection are a top priority for Twigex. If you have
discovered a security vulnerability, we appreciate your help in disclosing it to
us responsibly.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

Instead, email **security@twigex.com**, or use the **"Report a vulnerability"**
button on the repository's **Security** tab. This applies to both the
open-source project and the Enterprise Edition.

Please include:

- The affected version or commit
- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept

We are committed to working with you and will keep you updated throughout the
process. Reporters of valid issues will be publicly credited unless they prefer
to remain anonymous.

## Supported Versions

Security fixes are applied to the latest release. Please confirm the issue
reproduces on a current version before reporting.
